# An app for running small meditation retreats

A React app to help organize and manage small meditation retreats. Supports creation/editing of users, events, retreatants, default to do task schedules, and the ability to send registered attendees emails. Built with React (pre-hooks), Redux, Axios.

## Pre-reqs
- docker
- docker-compose
- React Management API

## Run locally
- Follow instructions in the React Management API to get the API running
- run `npm start`
